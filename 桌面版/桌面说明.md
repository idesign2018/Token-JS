# Token 计费工具 · Windows 桌面版

双击 `Token计费工具.exe` 打开独立窗口，不需要运行批处理、打开浏览器标签页或安装 Python。关闭窗口即可退出。适用于 Windows x64，需要 Microsoft Edge WebView2 Runtime；许多 Windows 10/11 电脑已预装。只有手动点击参考来源时，才会用系统浏览器打开外部网页。

EXE 可单独复制到可写目录。首次使用时会在 EXE 旁创建 `报价单文件`，也可以使用现有的同名目录。迁移时若要保留自定义报价，请一起复制该目录。软件不会将个人报价嵌入 EXE。EXE 内的网页是构建时快照；编辑网页版不会自动更新已生成的 EXE。

## 重新构建

在 Windows x64 使用 Python 3.12。切换到程序目录后，先安装 `桌面版/requirements.txt` 中的依赖，再执行：

```powershell
python -m pip install -r 桌面版/requirements.txt
python 桌面版/build_desktop.py
```

产物在输出目录 `dist`。关闭旧版应用后可替换 EXE。该版本未使用发行者代码签名证书。
